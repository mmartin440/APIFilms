<h2> Options to Get Started </h2>

<h4>- Click on the link to check out website </h4>
<a href="https://mmartin440.github.io/APIFilms/">Star Wars Project</a>

<h4>- Clone the Repo and launch the project locally </h4>
<ol>
<li>Open your terminal and clone the repository </li>
<li>Move into the project folder</li>
<li>Open the project folder in VS Code </li>
<li>Locate and open the <strong>index.html</strong> file</li>
<li>Make sure the <strong>Live Server</strong> extension is installed in VS Code</li>
<li>Click the <strong>Go Live</strong> button in the bottom-right corner of VS Code</li>
<li>Your browser should automatically launch the project locally</li>
</ol>
